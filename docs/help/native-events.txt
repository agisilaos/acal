Read events and mutate only this proof's independent fixtures

Usage:
  acal native events [flags]
  acal native events [command]

Available Commands:
  add         Create a uniquely marked timed fixture with an optional reminder
  delete      Delete one exact owned fixture; no production undo is available
  list        List occurrences in an explicit half-open interval (at most four years)
  remind      Replace all display alarms, or clear them, on an owned fixture
  show        Read one exact native event reference
  update      Change an owned fixture's title

Flags:
  -h, --help   help for events

Global Flags:
      --backend string          Backend: osascript (eventkit is not implemented) (default "osascript")
      --config string           Config file path
      --fail-on-degraded        Fail if backend health is degraded
      --fields string           Projected fields, comma-separated
      --json                    Output structured JSON
      --jsonl                   Output newline-delimited JSON
      --no-color                Disable color output
      --no-input                Disable prompts
      --plain                   Output stable plain text
      --profile string          Config profile (default "default")
  -q, --quiet                   Reduce success output
      --schema-version string   Output schema version (v1 only) (default "v1")
      --state-dir string        Absolute directory for isolated fixture ownership and durable operation records
      --timeout duration        Backend call timeout (e.g. 10s, 1m, 0 to disable) (default 15s)
      --tz string               IANA timezone for dates and output (empty uses system local)
  -v, --verbose                 Verbose diagnostics

Use "acal native events [command] --help" for more information about a command.
