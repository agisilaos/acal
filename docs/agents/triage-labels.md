# Triage labels

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Awaiting maintainer evaluation |
| needs-info | needs-info | Awaiting reporter information |
| ready-for-agent | ready-for-agent | Specified for autonomous implementation |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Use this mapping whenever a skill refers to a triage role.
